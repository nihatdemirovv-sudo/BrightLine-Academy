# BrightLine Academy

Süni intellekt dəstəkli DİM imtahanlarına hazırlıq platforması: buraxılış, qəbul (I–V ixtisas
qrupları) və magistratura. Tam Azərbaycan dilində.

**EN.** A working AI-powered exam-prep platform for Azerbaijan's national exams (DİM): AI question
generator, AI tutor, timed exam simulator, real-time multiplayer quiz, teacher–student panel.
Every test is documented in **input → output → verdict** format:
**34/34 tests pass**; **80** questions generated by the real AI (Gemini) — **0** quality issues;
**717** formulas — **0** KaTeX render errors.
See [`docs/test-neticeleri/README.md`](docs/test-neticeleri/README.md) (summary, English section at the top),
[`docs/test-neticeleri/TEST_GIRIS_CIXIS.md`](docs/test-neticeleri/TEST_GIRIS_CIXIS.md) (each test's input and output)
and [`docs/TESTLER.md`](docs/TESTLER.md) (how tests work). E2E tests run the app on a real HTTP port with an
in-memory H2 database and a stub AI server; a separate live test calls the real Gemini API and checks
every generated question automatically. Run: `cd backend && ./gradlew test`.

## 🏗️ Arxitektura

- **Frontend** (`src/`) — Next.js 16 App Router, TypeScript, Tailwind + shadcn/ui. Yalnız UI.
- **Backend** (`backend/`) — Spring Boot 3.3, Java 21. Bütün biznes məntiqi, verilənlər bazası
  (JPA + PostgreSQL, testdə H2) və AI inteqrasiyası (OpenAI-uyğun API, hazırda Gemini).

İki işə salma rejimi var:

1. **Ayrı proseslər (inkişaf)** — `npm run dev` frontend-i `localhost:3000`-də açır və `/api/*`
   sorğularını backend-ə proxy edir (`.env`-dəki `SPRING_BACKEND_URL`).
2. **Tək JAR (production)** — frontend statik export olunub Spring-in `resources/static` qovluğuna
   qoyulur, UI və API eyni portdan verilir.

## 🚀 Quraşdırma

Tələblər: Node.js 18+, Java 21, PostgreSQL (və ya `h2` profili).

```bash
# Backend konfiqurasiyası: nümunədən kopyala və real dəyərləri doldur (fayl git-ə düşmür)
cp backend/src/main/resources/application.yml.example backend/src/main/resources/application.yml

# Backend
cd backend && ./gradlew bootRun --args='--spring.profiles.active=h2'

# Frontend (ayrı terminalda)
npm install
npm run dev
```

### Production build (tək JAR)

```bash
NEXT_STATIC_EXPORT=1 npx next build
rm -rf backend/src/main/resources/static && cp -r out backend/src/main/resources/static
cd backend && ./gradlew bootJar        # → backend/build/libs/magistr.jar
```

Hər frontend dəyişikliyində `public/sw.js`-dəki `CACHE_VERSION`-u artır — yoxsa istifadəçilərin
brauzeri köhnə versiyanı keşdən göstərməyə davam edir.

> Windows-da istifadəçi qovluğunun adında boşluq varsa Gradle "Unable to establish loopback
> connection" xətası verə bilər. Həlli: `JAVA_TOOL_OPTIONS="-Djdk.net.unixdomain.tmpdir=C:/tmpjdk"`.

## 🧪 Testlər

```bash
cd backend && ./gradlew test
```

- **E2E testlər** (`backend/src/test/java/.../e2e`) — tətbiq real HTTP portunda, yaddaşdakı H2
  bazası ilə işə düşür; AI sorğuları testin öz saxta AI serverinə gedir (pulsuz, sürətli,
  təkrarlanan). Əhatə: müəllim qeydiyyatı → admin təsdiqi → canlı status; şəxsi mesajlar; bütün
  oxunmamış sayğaclar; sual generatoru (prompt quruluşu, LaTeX bərpası, mövzu bölgüsü, "Təsadüfi"
  fənn); AI Müəllim; günlük plan.
- **Unit testlər** — LaTeX/JSON bərpası (`JsonUtilTest`), prompt kitabxanası (`AiPromptsTest`).
- **Canlı AI keyfiyyət testi** — real API-yə sorğu göndərir, ona görə yalnız açıq şəkildə işə salınır:

  ```bash
  AI_LIVE_TEST=1 GEMINI_API_KEY=... ./gradlew test --tests '*LiveAiQualityTest'
  ```

  Bütün fənlər üzrə sual yaradıb strukturu, LaTeX balansını, cavab hərfini və dil qaydalarını
  avtomatik yoxlayır; bütün suallar `backend/build/reports/ai-quality.md`-yə yazılır.

Hər test **giriş → çıxış → nəticə** formasında hesabat yazır. Son real işə salınmanın nəticələri
(34/34 test, 80 real AI sualı, 717 düstur — 0 KaTeX xətası): [`docs/test-neticeleri/`](docs/test-neticeleri/README.md).
Ətraflı: [`docs/TESTLER.md`](docs/TESTLER.md).

## ✨ Funksiyalar

### Tələbə
- **Panel** — imtahan geri sayımı, statistika, Bilik Arenası kartı, nailiyyətlər, aktivlik istilik
  xəritəsi, tərəqqi radarı, AI zəif mövzular və zəif tərəflər, AI günlük plan.
- **AI Müəllim** — addım-addım izahlı söhbət (LaTeX), şəkillə məsələ həlli, səsli sorğu və səsli cavab, söhbətdə axtarış.
- **Sual Generatoru** — DİM tərzində A–E sualları; fənn (və ya "Təsadüfi"), say, çətinlik, mövzu; həndəsi fiqurlar.
- **İmtahan Simulyatoru** — vaxtlı mock imtahan (+4 / −1 / 0), nəticə və PDF.
- **İmtahana Düşən Suallar** və **İşlədiyiniz Sınaqlar** — real sual bankı və sınaq tarixçəsi.
- **Bilik Arenası** — real vaxtlı çoxnəfərlik bilik yarışı, reytinq.
- **Bal Hesablayıcı** (DİM düsturu), **Universitet Kodlaşdırması**, **Dərs Təkrarı** (AI mini-dərs + quiz),
  **Təkrar kartları** (SM-2), **Dərs Materialları**, **CV Yaratma**, **Dəstək**.
- **Müəllimim** — tapşırıqlar, materiallar, imtahanlar, müəllim sorğuları.
- **Mesajlar** — müəlliminlə şəxsi söhbət (real vaxt, şəkil).
- **Qruplar** — şifrəli qrup söhbətləri (cavab, redaktə, sil, səsli mesaj).
- **Oxunmamış sayğaclar** — qruplar, mesajlar, dəstək, Müəllimim və arena üzrə qırmızı badge ("99+"); tab başlığında ümumi say.
- PWA (quraşdırma, offline), bildirişlər, açıq/tünd rejim, Ctrl/⌘+K komanda paneli.

### Müəllim
- Tələbə axtarışı və himayə sorğusu, tələbələrin həftəlik fəaliyyəti, fərdi tapşırıqlar,
  materiallar, imtahan elanı və yoxlama, şəxsi mesajlar, qruplar, dəstək.
- Qeydiyyatdan sonra admin təsdiqi gözlənilir; təsdiq və ya rədd edildiyi an ekranda bildiriş çıxır.

### Admin
- Real imtahan sənədlərindən AI ilə sual çıxarma, tələbələr, müəllim təsdiqi (yeni sorğu anında
  bildiriş və badge), universitet keçid balları, dəstək, qruplar, arena, PDF materiallar.
